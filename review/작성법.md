# 복습자료 작성법

한 주에 파일 하나. `양식_복습자료.md`를 복사해서 이름을 `9월1주차 복습.md`처럼 바꿔 쓴다.

## 기본 구조

| 쓰는 것 | 뜻 |
|---|---|
| `# 재무회계` | 과목 (`#` 하나 + 띄어쓰기) |
| `## 재고자산` | 대챕터 (`#` 두 개) |
| `### 저가법` | 소챕터 (`#` 세 개) |
| `- 내용` | 세부내용 한 줄 (`-` + 띄어쓰기) |
| `**외울 말**` | 외울 것. 빈칸 버전에서 빈칸이 된다 |
| `*짧은 설명` | 짜바리 설명. `*` 뒤부터 괄호나 줄 끝까지가 설명이다 |

## 보강 요청 (줄 맨 끝에 붙인다)

| 쓰는 것 | 뜻 |
|---|---|
| `[분개]` | 이 줄에 분개를 만들어 붙여 줘 |
| `[표]` | 이 줄에 비교표를 만들어 붙여 줘 |
| `[함정]` | 헷갈리기 쉬운 것을 정리해 줘 |
| `[?]` | 알아서 제일 맞게 보강해 줘 (질문도 여기에) |

- 여러 개 붙여도 된다: `[분개][함정]`
- 표시가 없는 줄은 **그대로 옮기기만** 한다. 아무것도 덧붙이지 않고, 내용이 틀려 보여도 지적하지 않는다.

## 내가 직접 적는 분개

`[분개]`만 있는 줄 다음에 `차변 / 대변`으로 한 줄씩 적는다.
한쪽이 비면 `/` 앞이나 뒤를 비워 둔다.

```
[분개]
매출원가 20 / 재고자산평가충당금 20
현금 100 / 매출 80
         / 부가세예수금 20
```

## 내가 대충 그린 표

`[표]`만 있는 줄 다음에 대충 적는다. 칸은 띄어쓰기로 나누고 **빈칸은 `-`** 로 적는다.
다음 `-` 줄이나 `#` 줄이 나오면 표가 끝난 걸로 본다.

```
[표]
     기초   대손상계   기타   기말
BS   100    78         -      -
TAX  손불20  손불11    -      -
     손입12  손입20    -      -
```

칸 이름을 붙여 적어도 된다 (빈칸 많은 표는 이게 빠르다). 한 줄 = 한 행, `<칸>` 뒤에 값.
한 칸에 값이 여러 개면 쉼표로 잇고, 괄호는 그 값의 메모다.

```
[표]
사외적립자산 : <기초> 100, <증가> 20(적립), 10(이자수익), <감소> 8(OCI), <기말> 122
퇴직충당부채 : <기초> 80, <증가> 30(근무원가*과거근무원가도 즉시 인식), 8(이자비용), <감소> -, <기말> 118
```

- 괄호 안에 `*`를 쓰면 짜바리 설명이 된다: `30(근무원가*과거근무원가도 즉시 인식)`
  → 칸에는 `근무원가*`만 보이고, 설명은 표 바로 아래 각주로 들어간다.
- 한 표에 설명이 여러 개면 번호를 붙인다: `30(근무원가*1 설명), 8(이자비용*2 설명)`
- 적은 값은 **그대로** 옮긴다. 계산이 안 맞거나 내용이 이상해도 고치거나 지적하지 않는다. 궁금하면 `[?]`나 채팅으로 묻는다.
- 빈칸을 채워 주길 원하면 `[표][?]`로 적는다.

## 그 밖의 그림

`[공정흐름도]`처럼 대괄호에 그림 이름을 쓰고, 표와 같은 방식(`<이름>` 뒤에 값, 쉼표, 괄호 메모)으로 적으면 그림으로 그린다.

```
[공정흐름도]
<제1공정> 결합원가 : ???, 1공정산출물 : 제품A, B, C, 폐물S(C로인한 폐물)
<제2공정> 추가공정원가 : ???, 제2공정산출물 : AA(A), BB(B)
```

## 분개 색 (정리본에서)

**재무회계·세무회계 분개에는 항상** 칠한다. 원가관리회계 분개에는 칠하지 않는다.

| 색 | 계정 |
|---|---|
| 옅은 빨강 | 자산 · 부채 (차감계정 포함: 대손충당금, 감가상각누계액 등) |
| 옅은 노랑 | 수익 · 비용 (법인세비용 포함) |
| 옅은 파랑 | 자본 (자본금, 이익잉여금, 자기주식 등) |
| 옅은 초록 | 기타포괄손익(OCI) (재평가잉여금, FVOCI 평가손익 등. 자본이어도 초록이 우선) |

## 신경 안 써도 되는 것

- 띄어쓰기, 줄 간격, 번호, 문장 다듬기. 틀려도 다 읽힌다.
- 교재 쪽수는 적고 싶으면 괄호로: `(p.123)`

## 예시 (`9월1주차 복습.md`)

```
# 재무회계

## 재고자산

### 저가법

- 저가법은 **항목별** 적용이 원칙
- 평가손실 환입은 **최초 장부금액**까지만 [함정]

[분개]
매출원가 20 / 재고자산평가충당금 20

# 세무회계

## 대손금

### 대손충당금 한도

- 한도초과액은 손금불산입(유보) [?]

[표]
     기초   대손상계   기타   기말
BS   100    78         -      -
```

## 결과가 마음에 안 들면

정리본을 직접 고치지 말고 md나 채팅에 한 줄만 남긴다.
예: `저가법 분개 틀림, 교재는 매출원가로 처리`
→ 다시 만들고, 같은 실수가 반복되지 않게 규칙에 적어 둔다.
