# 복습노트 작업 규칙 (Claude용 요약)

이 파일만 읽고 작업한다. WORKLOG.md는 기록용이라 평소엔 안 읽는다. 사용자용 설명은 작성법.md.

## 파일
- 입력: `<과목> 복습노트.md` (과목별 누적). 출력: `<과목> 복습노트.html` + 공용 `sheet.css`, `sheet.js`.
- 아티팩트 (매번 `url`로 같은 곳에 다시 올림, `files`에 sheet.css·sheet.js):
  - 재무회계 복습노트: https://claude.ai/artifact/Q2eiE4XdG4ecdbZGjGG3xk
  - (새 과목은 만들 때 여기에 추가. 첫 게시만 icon "book")

## 순서 (토큰 아끼기)
1. md에서 `<!-- 반영 ... -->` 표시를 Grep으로 찾고, **그 아래만** 읽는다. 표시가 없으면 전체가 새것.
2. html은 전체를 다시 쓰지 않는다. 넣을 자리(해당 `<section class="ch">` 끝, 또는 `<footer class="foot">` 앞)를 Grep으로 찾아 Edit로 끼워 넣는다.
   목차 행과 머리의 `대챕터 N · 소챕터 N`, `N월 N주차`까지 누적도 고친다.
3. 게시: `url` + `file_path` + `files`. quickstart·디자인 안내는 새 과목 첫 게시 때만.
4. md의 반영한 부분 끝에 `<!-- 반영 YYYY-MM-DD: 여기까지 복습노트에 넣음 -->` 한 줄.
5. `review/` 커밋·푸시 (집·회사 공용).

## 옮기는 규칙
- 사용자 문장은 그대로(오타만 수정). 틀려 보여도 지적 안 함.
- 보강(`.add`)은 `[분개]`(내용 없음) `[표][?]` `[함정]` `[?]` 줄에만. `[?]`가 "표에 넣어줘"면 표에 `.addc` 칸.
- `[지시]`, 문장 속 `[…해줘]`, `{…해줘}` → 수행 결과를 그 자리(`.mine`)에. 지시 문장은 안 보임.
- `[분개] 내용` = 사용자가 쓴 분개(`.mine` 분개표). `[표]` 뒤 들여쓴 줄 = 표. `*1` 각주(각주 안 분개는 `.fnb`).
- `[분수] A/B` → `.frac`. `[델타]` → Δ. `[상황1]` `[유예딱지]` 등 → `<span class="tag">`.
- 분개 색(재무·세무만, 원가는 무색): 자산·부채 `a bs` / 수익·비용 `a pl` / 자본 `a eq` / OCI `a oci`.
- 대챕터 번호는 교재 장 번호(`13장`).

## HTML 부품
```html
<!-- 대챕터 -->
<section class="ch"><div class="ch-h"><span class="no">13장</span><h2>제목</h2></div> … </section>
<!-- 소챕터 -->
<div class="sub"><div class="sub-h"><h3>제목</h3><span class="wk">9월 1주차</span></div> <div class="mine">…</div> </div>
<!-- 내 노트: ul/li, 외울 것 <strong>, 짜바리 <sup class="fn">*</sup> + <p class="fline"> -->
<!-- 분개 (시점 칸 필요하면 th/td class="when") -->
<div class="tw"><table class="je"><thead><tr><th colspan="2">차변</th><th colspan="2">대변</th></tr></thead><tbody>
<tr><td class="acct"><span class="a bs">현금</span></td><td class="num dr-amt">100</td><td class="acct"><span class="a pl">매출</span></td><td class="num">100</td></tr>
</tbody></table></div>
<!-- 변동표: table.roll, 칸 <td><div class="v"><i>메모</i><b>100</b></div></td>, 기말 td.end, 합계 tr.sum, 빈칸 <div class="v empty">–</div> -->
<!-- 격자표: table.grid (가운데 정렬), 보강 칸 .addc -->
<!-- 표 각주: <p class="foot-n"><span class="fn">1</span><span>설명</span></p> -->
<!-- 계산: <div class="calc">…</div> -->
<!-- 보강 -->
<div class="add"><p class="add-t">보강 <span>[?] 주제</span></p> … <p class="note">…</p></div>
<!-- 함정 -->
<dl class="trap"><dt>✕</dt><dd>틀린 생각 → <strong>맞는 것</strong></dd></dl>
```
