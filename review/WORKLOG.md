# review 폴더 작업 기록

복습일마다 올리는 복습자료(md)를 **과목별 정리본**으로 만드는 작업 기록. 앱(CTA) 코드와는 따로다.

## 2026-09-24 — 방향 정함 (아직 실제 자료 없음)

### 사용자가 원하는 것
- 복습일에 `review/N월N주차 복습자료.md`를 올린다 (예: `9월1주차 복습자료.md`).
- 결과물은 **컴퓨터로 보거나 A4로 출력해서 보는 정리본**이다. 폰이나 앱에서 볼 용도가 아니다.
- 디자인을 갖춘 문서여야 한다.
- 노트를 옮기는 데서 끝내지 않고 Claude가 **분개와 표로 보강**한다.
- **과목별로 정리하고, 매주 누적한다.** 주차별 한 장씩 만드는 방식이 아니다.

### 시도했다가 버린 것
1. **앱용 카드 뷰어** (`build.mjs` + `viewer.html`): md를 `##` 기준으로 카드로 나눠 스와이프하고,
   굵은 글씨를 가리는 기능이 있었다. 폰 앱처럼 보는 용도라 방향이 맞지 않아 삭제했다.
2. **주차별 인쇄용 정리본** (`견본_복습정리.html`): 디자인과 보강 형식은 이대로 가져간다.
   다만 주차 단위라서 과목별 누적으로 바꿔야 한다.

### 가져갈 형식 (`견본_복습정리.html` 기준)
- 흰 종이 한 가지 모습이다(다크 모드 없음). A4 인쇄 CSS: `@page` 여백 14/13/16mm, 분개 표·계산 상자는 페이지 경계에서 안 잘리게 했다.
- 글꼴: 제목 Gowun Batang, 본문 IBM Plex Sans KR, 금액·숫자 IBM Plex Mono.
- 과목 색 태그: 재무 파랑 `#2248c4`, 세무 초록 `#0e7456`, 원가 보라 `#7a3fb0`.
- 구성: 머리(과목, 기간) → "한눈에 보기" 요약표 → 주제별 섹션.
  - `.mine`: 사용자 노트를 그대로 옮긴다. 굵은 글씨와 `==형광펜==`은 외울 것으로 표시한다.
  - `.add`(점선 파란 상자, "보강"): Claude가 추가한 내용이다.
    - 분개 표 `table.je`: 시점 | 차변 계정 | 금액 | 대변 계정 | 금액. 위에 `.calc`로 숫자 설정과 계산 과정을 쓴다.
    - 비교표, 구간별 한도표, 세무조정 순서(조정·소득처분)를 넣는다.
    - "헷갈리기 쉬운 것" ✕ 목록을 넣는다.
- 빈칸 버전 토글: 굵은 글씨와 형광펜을 밑줄 빈칸으로 바꾼다. 탭하면 답이 보이고, 이 상태로 인쇄하면 셀프 테스트지가 된다.
- 인쇄 버튼은 로컬 파일로 열었을 때만 보인다. 아티팩트 안에서는 `window.print()`가 막혀 있다.
- 꼬리말: "보강 정리는 Claude가 작성. 교재와 대조."

### 다음에 할 일 (과목별 누적)
- 주차 md가 올라오면 주제마다 과목을 판별해서 **과목별 정리본에 추가**한다.
  (예: `review/재무회계.html`, `review/세무회계.html` …)
- 과목 정리본 안에서는 주제를 단원 순서로 묶고, 주제마다 어느 주차에 복습했는지 표시한다.
  같은 주제를 다시 복습했으면 새로 만들지 않고 기존 주제에 합친다.
- 과목마다 아티팩트를 하나씩 두고, 매주 같은 URL로 다시 올린다.
- 정해야 할 것: 과목을 나누는 단위(재무회계/원가/법인세/소득세/부가세/세법학 등 세부 과목까지 나눌지),
  단원 순서의 기준(교재 목차).

## 2026-09-25 — 입력 양식과 규칙 정함

손글씨가 불편해서 md로 입력한다. 걱정은 "입력한 것과 결과가 달라서 조정하는 데 시간이 드는 것"이라
Claude가 다듬거나 추측하지 못하게 규칙을 정했다.

- 양식: `양식_복습자료.md`(빈 틀), 작성법과 예시는 `작성법.md`.
- 파일은 한 주에 하나: `N월N주차 복습.md`. 문법: `# 과목`, `## 대챕터`, `### 소챕터`, `- 세부내용`, `**외울 것**`,
  줄 끝 보강 요청 `[분개]` `[표]` `[함정]` `[?]`.
- 사용자가 직접 적는 분개: `[분개]` 단독 줄 다음에 `차변 계정 금액 / 대변 계정 금액`. 한쪽이 비면 `/` 앞뒤를 비운다.
- 사용자가 대충 그린 표: `[표]` 단독 줄 다음에 띄어쓰기로 칸 구분, 빈칸은 `-`. 다음 `-`나 `#` 줄에서 끝.
  `[표][?]`면 빈칸을 채운다.
- 분개 계정 색(옅은 형광): 자산·부채(차감계정 포함) 빨강, 수익·비용(법인세비용 포함) 노랑, 자본 파랑,
  OCI 초록(자본이어도 초록 우선). `table.je` 계정 칸에 적용한다.
  **재무회계·세무회계 분개는 항상 칠하고, 원가관리회계 분개는 칠하지 않는다.**
- **사용자 문장은 바꾸지 않는다.** 오타만 고치고, 바꾸는 건 형식(제목·굵게·표 모양)뿐이다. → `.mine`
- **보강(`.add`)은 표시가 달린 줄에만 붙인다.** 표시가 없는 줄에는 아무것도 덧붙이지 않는다.
  `[?]`는 그 줄에 제일 맞는 보강을 Claude가 고른다(질문이면 답을 단다).
- 사용자가 고칠 게 있으면 시트가 아니라 md나 채팅에 한 줄로 남긴다. Claude는 다시 만들고,
  반복될 만한 지적은 아래 "사용자 피드백"에 적어 다음 주부터 지킨다.

- 짜바리 설명은 `*`: `*` 뒤부터 괄호 끝(괄호 밖이면 줄 끝)까지. 표 칸에서는 메모 뒤에 `*` 표시만 두고 설명은 표 아래 각주로,
  일반 줄에서는 그 줄 아래 작은 글씨로 단다. `**굵게**`와는 별개다.
  여러 개면 `*1 설명`, `*2 설명`처럼 번호를 붙인다(번호 뒤 띄어쓰기부터 설명). 정리본에서는 위첨자 번호 + 표 아래 번호순 각주.
- 표 입력(칸 이름 방식): 한 줄 = 한 행, `<칸>` 뒤에 값, 한 칸 여러 값은 쉼표, 괄호는 메모. 정리본에서는 한 칸 안에 한 줄씩 쌓고
  메모는 금액 왼쪽에 작게, `-`는 흐린 –, 검산 표시는 넣지 않는다. 미리보기: https://claude.ai/artifact/TJbDsna836go7AdMPSDdAS
- 과목별 누적은 그대로: 주간 파일의 `# 과목`마다 해당 과목 정리본의 같은 대챕터·소챕터 밑에 합친다.

- 견본을 새 규칙으로 다시 만듦: 입력 `견본_9월1주차 복습.md` → 출력 `견본_복습정리.html`(재무회계 과목 정리본, 같은 견본 URL).
  과목 제목 → 목차(대챕터·소챕터·복습한 주) → 대챕터(`01` 번호, 굵은 선) → 소챕터(주차 칩) 순서.
  외울 것(`**`)은 노란 형광 대신 **굵게 + 파란 밑줄**로 바꿨다(수익·비용 노랑 형광과 헷갈리지 않게).
  사용자가 적은 분개는 `.mine` 안에 시점 칸 없는 분개표, Claude 보강 분개는 `.add` 안에.

### 사용자 피드백 (누적)
- 2026-09-25 **기조: 입력한 값을 그대로 출력한다.** 계산이 안 맞거나 개념이 틀려 보여도, 오타 같아 보여도
  정리본과 채팅 어디서도 먼저 지적하지 않는다. 애매한 건 사용자가 `[?]`나 채팅으로 직접 묻는다.
